# Capanema Design System

This repository contains the source files, version history, and documentation for the Capanema Design System.

The system powers capanema.io, a personal portfolio and publishing platform focused on engineering leadership, technology strategy, product thinking, organizational scaling, and technical case studies.

The design language is inspired by the clarity of Linear, the craftsmanship of Stripe, and the restraint of Vercel. It emphasizes quiet confidence, premium quality, technical sophistication, mature aesthetics, and exceptional readability.

The repository serves as the single source of truth for all design assets, including Foundation, Tokens, Components, Patterns, design reviews, and future iterations of the system. All `.pen` files are versioned here to maintain a complete history of design decisions and evolution.
